## 이 앱은 누구를 어떻게 돕는가 (한 문장)

> 부산에서 살 동네를 고르는 사람이 "역세권이니 동네가 유지되겠지"로 판단하려 할 때,
> 이 앱은 **역세권이 인구를 늘리지는 않고 줄어드는 속도를 5년에 4~6%p 늦출 뿐이며,
> 어느 층의 동네인지가 그보다 큰 차이(9.2%p)를 만든다**는 논문의 결과를
> 그 동네의 숫자로 보여 준다.

## 사용자가 할 일 세 가지

1. **내 동네에서 "역세권"이 몇 %p를 설명하는지 본다** — 행정동 이름을 넣으면, 그 동네가 속한 층에서 역세권 여부로 실제 갈렸는지를 논문 수치 그대로 답한다.
2. **같은 자료를 세 가지 척도로 재 본다** — 거리 / 역 개수 / 역세권 여부 세 탭을 바꿔 가며, 척도에 따라 관계가 보이기도 사라지기도 하는 것을 직접 본다.
3. **거리가 비슷한 두 동네를 나란히 놓는다** — 역까지 거리는 같은데 인구 변화가 반대인 짝을 보고, 거리만으로 고르면 안 되는 이유를 확인한다.

## 논문의 어느 결과를 실제로 쓰는가

앱 안의 판정과 숫자는 전부 논문에서 그대로 옮긴 것입니다. 코드의 `P` 객체 한 곳에 모아 두었습니다.

| 쓰는 곳 | 논문 결과 |
|---|---|
| 1·2단계 판정 규칙 | 사전 등록: \|ρ\| ≥ 0.2 이고 p < 0.05 이면 가설 지지 |
| 2단계 ① 탭 | 최근접역 거리 — Spearman ρ = −0.1246, p = 0.07503 → **기각** |
| 2단계 ② 탭 | 1km 내 역 개수 — ρ = +0.1728, p = 0.01324 → 유의 |
| 2단계 ② 막대 | 역 개수 구간별 중앙값 0개 −12.52 / 1개 −9.99 / 2개 −7.15 / 3개↑ −6.21 |
| 2단계 ③ 탭 | 역세권 여부 — 중앙값 −7.79%(n=130) 대 −12.52%(n=75), Mann-Whitney p = 0.01901 |
| 1·3단계 층 판정 | 기성시가지 −6.84 대 −12.69 (p = 0.0032) / 원도심 −11.57 대 −15.91 (p = 0.1803) / 외곽신시가지 n = 13 판단 유보 |
| 1단계 층 중앙값 | 원도심 −12.96 / 기성시가지 −8.08 / 외곽신시가지 −3.73 |
| 2단계 ① 표 | 거리 5분위별 중앙값 −8.08 / −7.31 / −7.83 / −11.45 / −12.61 |
| 3단계 어긋난 짝 | 논문 4.4절 "가설과 어긋난 개별 사례" 두 목록에서 고른 6쌍 |

**가설이 기각된 논문으로 무엇을 만들었나** — "차이가 없다"가 아니라 **"재는 방법에 따라 갈린다"**를
쓸 수 있게 만들었습니다. 그래서 이 앱은 원도심 동네에 대해서는
"역세권이라는 사실로는 이 동네를 설명할 수 없습니다"라고 **그대로 말합니다.**
논문의 실질적 함의가 그것이기 때문입니다.

설치할 것이 없습니다. **`index.html` 을 더블클릭하면 열립니다.**

```
1) 이 폴더를 새 임시 폴더에 푼다
2) index.html 을 브라우저로 연다   (또는 위 주소를 새 시크릿 창에서 연다)
3) 화면의 1 → 2 → 3 순서대로 해 본다
```

- 205개 행정동 값이 `index.html` 안에 그대로 들어 있어 인터넷 없이도 동작합니다.
  (글꼴만 Google Fonts에서 받아오며, 못 받아도 대체 글꼴로 정상 표시됩니다.)

## 잘못된 입력을 넣어도 멈추지 않습니다

없는 이름·숫자·특수문자·빈칸·HTML 조각을 넣어도 앱이 멈추지 않고,
직전 결과를 그대로 둔 채 "그런 행정동은 없습니다"와 비슷한 이름 후보를 보여 줍니다.
입력은 공백·기호를 지우고 부분 일치로 찾으므로 "중앙", "해운대 반송1동" 같이 넣어도 걸립니다.

## 이 앱으로 말할 수 없는 것

논문의 한계를 그대로 물려받습니다. 상관이지 인과가 아니고, 주택 공급·재개발을 통제하지 못했으며
(강동동 +376%가 그런 경우로 보입니다), 행정동을 중심점 한 점으로 대표했고, 두 시점만 비교했습니다.
외곽신시가지 13개 동에 대해서는 논문이 판단을 유보했고 **이 앱도 유보합니다.**
